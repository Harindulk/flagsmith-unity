Flagsmith has no Unity SDK.

Its FAQ points Unity developers to the .NET SDK. That SDK polls and sends events with System.Threading.Timer, Task.Run and Task.Delay, and none of those run in a WebGL build.

The Flagsmith team's own "Unity SDK" issue, opened in March 2024, was closed as not planned in November 2026. Firebase Remote Config, Statsig, ConfigCat and Unity's Remote Config all support Unity.

Flagsmith for Unity runs on Unity's main thread with UnityWebRequest, caches the last good flags on disk, and speaks Flagsmith's new Experimentation API. Issue #3623 · the FAQ

A/B test it on half the players

Call GetExperimentFlag at the moment a player sees the thing under test, and TrackEvent when they succeed. Flagsmith Experimentation does the statistics.

var tut = flagsmith.GetExperimentFlag("tutorial_style");
ShowTutorial(tut?.Value ?? "text");
// later
flagsmith.TrackEvent("first_run_complete");

Exposures are recorded only for enrolled players, and each one is sent once per session. Events are batched under the 2 MiB limit, saved to disk when the app pauses and retried after network errors.

Tune it without leaving Unity

Window > Flagsmith lists an environment's flags. Flip a toggle or edit a value, press Save, and the game in Play mode picks it up on its next refresh.

Enter a player ID and the same window changes a flag for that player only: one tester's phone, or the game you are running.

The admin token lives in EditorPrefs on your machine, so it never ends up in the project or in version control.

Full guide

Add the package

Package Manager > + > Install package from git URL. Unity 6 or newer.

https://github.com/Harindulk/flagsmith-unity.git?path=/com.flagsmith.unity

Copy your client key

Flagsmith > your environment > SDK keys. Never a ser. key.

Environment Key: your-client-key

Add the component

On a GameObject in your first scene. Paste the key; leave the API URL for Flagsmith Cloud.

Add Component > FlagsmithBehaviour

Bind fields to flags

A bool follows the flag's on/off state. Your initialiser is the offline default.

[FlagsmithValue("run_speed")] float runSpeed = 7f;
[FlagsmithValue("double_jump")] bool doubleJump;
void Awake() => flagsmith.Bind(this);

Or read them directly

Typed, culture-safe, with a fallback for every read.

float s = flagsmith.Flags.GetValue("run_speed", 7f);
bool on = flagsmith.Flags.IsEnabled("new_shop");

Add traits for segments

Sent with the next refresh, so segments and overrides work per player.

flagsmith.Traits["level"] = 12;

Refresh every second or two

Set Refresh Seconds on the component while you tune.

Refresh Seconds: 2

React to changes

Runs on the main thread, only when something actually changed.

flagsmith.FlagsChanged += f => ui.Refresh(f);

Ship with 60 seconds

Every refresh is one request per player.

Refresh Seconds: 60

Create the experiment

A multivariate flag, a metric on an event, and an experiment that uses both.

tutorial_style: text | hand

Record the exposure

When the player actually sees the variant, not at startup.

flagsmith.GetExperimentFlag("tutorial_style");

Record the outcome

Batched, saved on pause, retried after errors.

flagsmith.TrackEvent("first_run_complete");

cd server && docker compose up -d
